## 🧩 About

**Warframe overlay** is a curated list of Warframe open-source tools:

- **Overlays** — on-screen helpers, layout notes, enemy overlay, loot tracker
- **Quality-of-Life Helpers** — build planner, resource tracker, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Mission Helpers
- Enemy overlay — visualize nearby enemies on overlay
- Loot Tracker — highlight resource and mod drops
- Mission Timer — track objective progress
- Damage Numbers — review combat statistics

### 🎨 Loadout & Cosmetics
- Build Planner — theorycraft mod configurations
- Fashion Frame Notes — organize appearance presets
- Resource Calculator — plan crafting requirements

### 🏋️ Practice Layout
- Simulacrum Notes — test builds in controlled environment
- Ability Timer — track cooldowns and buffs
- Movement Helper — practice advanced parkour routes
